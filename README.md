# ADDS - Autonomous Drone Delivery System

ADDS is a modern web application for booking autonomous drone delivery services, similar to Ola Cabs but for drone deliveries.

## Features

- User Authentication (Login/Signup)
- Interactive Map with Pickup and Dropoff Locations
- Real-time Distance Calculation
- Multiple Drone Options with Different Specifications
- GPS Tracking System
- Order Confirmation Popup
- Responsive Design

## Setup Instructions

1. Clone the repository
2. Replace `YOUR_API_KEY` in `booking.html` with your Google Maps API key
3. Open `index.html` in a web browser

## Requirements

- Modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection for Google Maps integration
- Google Maps API key

## File Structure

- `index.html` - Login/Signup page
- `booking.html` - Main booking interface
- `styles.css` - Styling for the entire application
- `script.js` - JavaScript functionality

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Maps API
- Geolocation API

## Note

This is a frontend-only implementation. For a complete application, you would need to:
1. Implement backend authentication
2. Set up a database for user accounts
3. Implement payment processing
4. Add real-time tracking system
5. Set up drone management system
